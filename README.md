# AI - Powered Application

An application that trains on historical SMP fitness data, predicts whether a new day will hit the 10,000-step goal, and generates a coaching message based on the prediction and input values.

## What It Does

-Trains on historical SMP fitness data.

-Predicts whether a new day will hit the 10,000-step goal.

-Generates a coaching message based on the prediction and input values.



## Stack

Python, scikit-learn, NumPy, FastAPI
